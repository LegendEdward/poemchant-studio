# 模型与公开发布范围

## 公开规则 R0

R0 没有训练权重。代码中的数值是可修改的工程假设，不是从新实验获得的规律，不是吟诵传统的统一公式。

- 拼音候选：pypinyin 0.55.0；上下文预测仍可能读错，多音候选保留。
- 历史调类及韵部：固定平水韵二手转录；多类别不强行选定。仅在原字缺失时尝试 OpenCC 字形代理，原诗不变。
- 字长权重：平 1.15、上 1.05、去 0.95、入 0.75、未知 1.0；非句末第 2/4 字乘 1.08，句末乘 1.6；以本句非句末权重中位数归一化，再乘用户字长基准。
- 5 个等相位音高控制点，半音轮廓：一声 `[2,2,2,2,2]`、二声 `[-2,-1,0,2,3]`、三声 `[-1,-3,-4,-2,1]`、四声 `[3,2,0,-2,-3]`、轻声 `[0,-1,-1,-1,-1]`；每个后续字加 −0.3 半音句内走向。现代调号未知时，音高留空。
- 第 2/4 字后可显示分节候选，但不添加声音空档。
- 无校准概率、无真实声学支持、无自然度或历史真实性保证。

原始数值和散列在每份工程的来源字段中记录。编辑后的数值单独保存；不会改变原始规则谱或原研究模型。

## 可选本地研究模型

仅支持已有 `prosody_v1` 模型格式。自动标签默认 M2；用户显式提供标签时默认 M3。输入的现代/历史调类来自各自候选，不把历史调类当作现代声调；字典韵部也不自动映射成语料中的 0–3 韵标记。

包至少包含原始 `release_manifest.json`、`bundle.json`、`calibration.json`、`text_exposure.json` 以及清单列出的全部文件。ZIP 可以直接以这些文件为根，或使用单一顶层文件夹。应用核对每个文件散列和预测实现版本，压缩/解压总量均限制为 16MB，拒绝越界路径、符号链接、重复路径和不支持的文件类型。

包内 `.py` 只作来源散列核对，不执行；实际推理始终使用应用内置的固定实现。此机制不是给外部任意代码开设插件入口。

**公开版没有附带这个包，也没有自动下载地址。** 已有模型来自研究使用的录音和标注，当前没有记录充分的再分发许可。用户须自行判断其持有材料的使用权限。本项目的 MIT 代码许可不会覆盖模型或数据的额外权利。

导入后，模型保存在本机应用数据目录。公开的同一个应用二进制可以加载它，无须访问原研究工程。卸载应用不会自动删除稿件和模型；请自行备份。

## 名称与结论边界

导入研究模型后，可以描述为数据驱动的候选吟诵谱生成；未导入时，应称为规则模式的谱生成与编辑工具。音高模板较粗，时长区间较宽，不能用曲线编码误差代替新文本旋律预测误差。任何模式都没有自动获得专家审定、特定流派认证或人声自然度认证。
