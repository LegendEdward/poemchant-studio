## 吟谱 · PoemChant Studio 2.0.0

独立的候选吟诵谱生成、标注与编辑应用。输入五言或七言诗，可逐字编辑拼音、历史调类、韵部候选、分节、备注、时长和连续音高，保存多稿并导出完整工程、SVG、CSV/JSON、MusicXML、MIDI与器乐 WAV。

- Mac 安装包内含运行环境，适用于 Apple Silicon / macOS 14+。
- 每次保存建立新稿，保留生成原稿与修改记录；未知音高保持断开。
- 公开包提供透明规则 R0，没有训练权重。支持自行导入兼容的本地研究模型，不包含录音、训练词表或私人研究材料。
- 原创代码 MIT 开源；第三方许可和 AI 参与范围已列明。
- 安装包只有本地临时签名，没有 Apple Developer ID 签名或公证。也提供源码包和 Python wheel。

生成谱尚未经过独立吟诵专家审校；器乐试听不是人声，不能称为特定传统或历史吟调的认证复原。软件检查和实际 Mac 操作记录见仓库 `docs/VERIFICATION.md`。

下载后可用 `SHA256SUMS.txt` 对照散列。源码安装见 README，模型格式见 `docs/MODELS.md`。
