# 使用说明

## 制作与标注

输入四句或八句、每句五字或七字的完整诗。题名、作者分别填写。简体、繁体原字保留；本应用没有替你进行古籍版本校勘。

「字长基准」越大，整体越慢；「音区基准」越高，试听音区越高。它们是制作控制值，不是从当前诗文测得的真实演唱参数。生成方式旁会显示使用规则还是本地训练模型。

生成后，下方每个字都是可选择的编辑入口：

- 拼音采用数字调号，例如 `yue4`。改拼音会同步末尾现代调号；未知可留空。输入不一致会在保存时提示。
- 历史调类独立于现代调号；平、上、去、入候选不确定时可保留未知。
- 韵部用于编辑标注，不等于已经验证全诗押韵。多候选应核对后填写。
- 「分节」只在谱面上加标记，不在声音里切出微小空档。
- 字长可设 50–5000 毫秒；音高可设 30–2000Hz；全诗试听最长 180 秒。
- 拖动曲线圆点或输入 Hz 都可修改音高。清空控制点保留未知片段；不会跨空缺插值。每字最多 32 点。
- 逐字备注最多 500 字，全诗备注最多 4000 字，可记录读音依据或争议。

「恢复本字生成值」恢复这个字的时长与音高，不撤销另外填写的标注。「保存修改并生成新稿」将当前谱和标注另存；之前的保存稿仍可打开。

## 标注与声音的关系

保存读音等标注不会自动改变已生成的时长和音高。需要用改过的调类重算时，选择「按当前标注重新生成」。这个操作会提示，并在新稿中替换手工音高和时长；旧保存稿保留。填写的拼音音节本身不是发声合成指令；应用没有人声引擎。

CSV 导出包含每字所在句、字位、原字、拼音、现代调号、历史调类、平仄候选、韵部、分节、字长、句内起止时间、备注、来源及生成模式。CSV 中可能被表格软件识别为公式的备注加单引号保护，完整 JSON 保留原值。

## 保存、备份与恢复

每次生成或保存，都写入本机应用数据目录的一个新文件夹。「最近保存」显示最近 8 稿；旧稿不会自动删除。需要长久保留时，导出「完整工程」或「全部打包」，也可备份整个 `projects/` 文件夹。

再次打开应用后，从「最近保存」选择稿件，或点「打开工程文件」导入 `project.poemchant.json`。旧版 `score.project.json` 可以导入生成数值，但不包含新标注层。研究模型产生的工程需要相同本地模型；缺少模型时会提示，不会替换成规则模式冒充原稿。

快捷键：⌘/Ctrl+S 保存新稿；⌘/Ctrl+O 打开工程。未保存的编辑会有提示，并暂停导出；保存后再导出可避免标注与谱面版本不一致。

## 常见问题

**为什么某些调类或音高留空？** 这是保留未知；不是漏印。候选谱没有足够依据时，不应伪装成真实古音或旋律。

**为什么声音不像真人？** 目前提供器乐试听，用于检查时间和音高，不合成吟诵人声。

**为什么没有模型？** 公开版不再分发录音派生的模型和训练词表。规则模式可以直接使用；已有合法可用研究包的用户可本机导入。

**能用作教学定本吗？** 软件回读和文件校验不等于艺术审定。用于正式教学或传统风格介绍前，需要相应专业核对。

**应用启动失败？** 当前 Mac 包要求 Apple Silicon、macOS 14+。本机日志位于应用数据目录 `application.log`；提交问题时去除私人路径或自填诗文。源码方式可重新构建；不要关闭系统安全保护来解决启动问题。
