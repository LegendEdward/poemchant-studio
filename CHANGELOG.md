# Change log

## 2.0.0 — standalone application

- Isolated application source from the research workspace and frozen manuscript results.
- Added a self-contained Apple Silicon/macOS native shell with bundled Python, WKWebView, loopback service, file dialogs, persistent revisions and unsaved-change protection.
- Added a public, explicitly untrained R0 mode and an optional local research-model import path; recording-derived model assets are excluded from the public distribution.
- Added an editable annotation layer: numbered pinyin, modern tone, historical tone class, rhyme candidate, caesura marker and per-character / poem notes.
- Added direct pitch-point editing and drag controls, duration editing, explicit re-inference, restoration and missing-pitch preservation.
- Added annotated SVG, CSV/JSON, complete editable projects and actual MusicXML/MIDI/WAV export, with file hashes and immutable original scores.
- Added correctness and safety regression checks, third-party notices, source build instructions and release packaging.

This is an application release, not a new confirmatory research experiment or artistic-quality certification.
