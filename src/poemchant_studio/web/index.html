吟谱 · PoemChant Studio 2.0.0

本应用生成古诗的候选吟诵谱，并支持逐字标注和编辑。它不撰写新诗，也不合成人声。

公开规则 R0 使用明确记录的工程规则，没有经过训练或艺术真实性验证。本地研究模式需要自行导入既有模型；研究模型仍是弱参考候选，不能当作历史吟调复原。

拼音来自 pypinyin；历史调类和韵部来自平水韵的二手机器转录。多读音、字形转换和未知条目需要核对，用户修改也不会自动成为专家审定。

操作：输入诗句 → 生成 → 逐字编辑 → 保存新稿 → 导出。自动保存的各稿保留在本机应用数据目录，不上传诗文或标注。

快捷键：⌘/Ctrl + S 保存；⌘/Ctrl + O 打开工程。导出前先保存修改。软件在当前设备的检查不代替独立音乐学评估。
